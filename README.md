## 📱 Objetivo Principal
El objetivo principal de la materia **Programación IV** es el **Desarrollo Móvil**, enfocándose en la creación, diseño e implementación de aplicaciones nativas y multiplataforma eficientes, escalables y orientadas a la experiencia de usuario (UX/UI), utilizando un ecosistema moderno de tecnologías y herramientas de vanguardia.

---

## 🔍 Mini Concepto de las Tecnologías Utilizadas

### 1. Node.js
* **Qué es:** Un entorno de ejecución para JavaScript fuera del navegador, basado en el motor V8 de Google.
* **Uso en la materia:** Permite desarrollar servicios de *backend*, APIs RESTful y lógica del lado del servidor de forma rápida y asíncrona, sirviendo como soporte o puente para las aplicaciones móviles.

### 2. React Native
* **Qué es:** Un framework de código abierto creado por Meta basado en React y JavaScript.
* **Uso en la materia:** Permite construir aplicaciones móviles nativas reales tanto para Android como para iOS utilizando una única base de código compartida, aprovechando componentes nativos del dispositivo.

### 3. Kotlin
* **Qué es:** Un lenguaje de programación moderno, tipado estáticamente y totalmente interoperable con Java, impulsado oficialmente por Google para el desarrollo en Android.
* **Uso en la materia:** Se emplea para el desarrollo nativo en Android, garantizando un código más conciso, seguro (evitando errores por nulos) y de alto rendimiento.

### 4. Dart
* **Qué es:** Un lenguaje de programación orientado a objetos, optimizado para clientes, desarrollado por Google.
* **Uso en la materia:** Es el lenguaje base utilizado para escribir toda la lógica y la interfaz de usuario en el desarrollo con Flutter.

### 5. Flutter
* **Qué es:** El kit de desarrollo de interfaz de usuario (UI SDK) de código abierto creado por Google para compilar aplicaciones compiladas de forma nativa para móviles, web y escritorio desde una sola base de código mediante Dart.
* **Uso en la materia:** Fundamental para el diseño y construcción de interfaces multiplataforma fluidas, altamente personalizables y de alto rendimiento.

## 📂 Estructura del Repositorio
Este repositorio está diseñado como un monorepo o directorio unificado que contiene diversos proyectos y prácticas enfocadas en las tecnologías mencionadas:
* `/node` -> Proyectos de backend y servicios con Node.js.
* `/react-native` -> Aplicaciones móviles multiplataforma basadas en JavaScript/React.
* `/kotlin-android` -> Desarrollo nativo para Android.
* `/flutter-dart` -> Aplicaciones móviles multiplataforma basadas en Flutter y Dart.
